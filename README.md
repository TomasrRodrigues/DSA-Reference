# DSA-Reference - Complete Study Guide

This repository serves as a technical reference for the fundamental principles of Data Structures and Algorithms (DSA). It provides a rigorous, synthesized overview of computational logic, asymptotic analysis and structural invariants, complemented by standardized C++ implementations.

The content is structured to serve as both a high-signal study guide and a professional architectural reference, prioritizing technical precision and efficiency of information.

---
## Table of Contents

### I. Foundations

Analysis of algorithm correctness and the mathematical frameworks for performance measurement.

- **[Algorithm Correctness](/AlgorithmCorrectness/)**: Formal specifications, preconditions, postconditions, and proof techniques using loop invariants and variants.

- **[Algorithm Complexity](/AlgorithmComplexity/)**: Asymptotic analysis ($O, \Omega, \Theta$), space-time trade-offs, and classification of computational growth rates.

- **[Abstract Data Types (ADT)](/AbstractDataTypes/)**: Principles of data abstraction, encapsulation, and interface design within the C++ paradigm.



### II. Data Structures
Formal implementations and structural properties of linear and hierarchical organizations.

- **[Linear Data Structures](/LinearDataStructures/)**: Contiguous and linked representations, iterator patterns, and the mechanics of LIFO/FIFO structures.

- **[Binary Trees](/BinaryTrees/)**: Morphological properties, balanced architectures (AVL, Red-Black), and recursive traversal methodologies.

- **[Priority Queues and Heaps](/PriorityQueuesHeaps/)**: Binary heap invariants, heapification protocols, and priority-based scheduling.

- **[Hash Tables](/HashTables/)**: Stochastic mapping, collision resolution strategies (chaining and open addressing), and load factor optimization.



### III. Algorithmic Patterns
Analysis of search, sort and graph-theoretic algorithms

7. **[Searching Algorithms](/Searching/)**: Comparative analysis of sequential and logarithmic search patterns across diverse data manifolds.

8. **[Sorting Algorithms](/Sorting/)**: Detailed study of comparison-based (Quick, Merge, Heap) and distribution-based (Counting, Radix) sorting logic.

11. **[Graphs](/Graphs/)**: Representational models (Adjacency Matrices/Lists), topological properties, and fundamental traversal algorithms (DFS/BFS).
